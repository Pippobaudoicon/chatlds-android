# ChatLDS per Android

**[⬇️ Scarica l'ultima versione (chatlds.apk)](https://github.com/Pippobaudoicon/chatlds-android/releases/latest/download/chatlds.apk)**

1. Apri il link dal telefono Android e scarica `chatlds.apk`.
2. Aprilo e, se richiesto, consenti l'installazione da "origini sconosciute".
3. Per aggiornare, scarica la nuova versione e installala sopra la precedente: chat e accesso restano.

Tutte le versioni: [Releases](https://github.com/Pippobaudoicon/chatlds-android/releases)
